## Answers to the six pending design questions

These answers were first posted in [issue #4 at 18:06 UTC](https://github.com/ykzeng-yale/DTR-AgentEvals/issues/4#issuecomment-5744198051), before this monitoring cycle. The experiment host's committed handoff still marks them unanswered. This is a communication gap, not evidence that its worker had received or implemented those answers before freezing the design.

1. **L1 scope.** Function synthesis is acceptable as a scoped coding-agent feasibility and estimator-calibration study. It does not establish general-purpose agent performance or independently certify Seatbelt containment. Longer tool-use benchmarks remain later work.
2. **Stopping.** Keep the realistic stopping rule and deduplicate coincident policies. Name the event **visible-validator pass**, which need not imply hidden-test success. Forcing subsequent calls after that event would define a different intervention and requires separate specification.
3. **Finite-sample certificate.** Report a vacuous bound honestly, with constants from the actual score construction. Asymptotic task-level simultaneous intervals and finite-sample guarantees are separate procedures. An empirical-Bernstein replacement needs its own valid theorem and implementation. Also resolve the cross-fitting mismatch identified below before applying the current certificate to these scores.
4. **Visible tests.** Retain frozen tests and their generation procedure/hashes as part of the primary environment. Regeneration could also define a valid study if its law is common across policies and the realized environment is restored when branching. Global freezing is helpful, not a mathematical necessity. The reference-based certification and hidden-input-overlap filtering should be described transparently; neither excludes benchmark memorization by the underlying models.
5. **Overlap design.** A separate logger-sharpness parameter is justified. Preserve default behavior and archived outputs; vary sharpness and eligible horizon separately while holding transition/reward mechanisms fixed. Audit actual propensities and likelihood ratios, since different nominal floors can induce identical loggers. The reference-library implementation remains queued with the theory workstream; no new sweep is requested now.
6. **Shared-log efficiency.** Savings are conditional on eligible opportunities, overlap, candidate-class size and total collection/fitting cost. Preserve unfavorable results. Few decisions and supported stochastic targets do not guarantee that off-policy estimation beats direct execution. The existing S1 break-even calculations remain workstream-reported until independently checked.
