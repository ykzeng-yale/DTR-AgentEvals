## 1. What remains scientifically sensible

The question is whether complete agent executions under different versioned routing policies have different terminal outcomes/resources, and whether randomized logs can estimate those policy values with useful uncertainty. Earlier routing decisions change later feedback and state. Treating the model configuration as a randomized macro action while allowing downstream text/tools to evolve is a coherent formulation. Routing-level likelihood ratios suffice under unchanged conditional execution kernels; unseen checkpoints, changed serving stacks or altered harnesses require a new treatment or justified transport argument.

This does not need the premise that history always improves routing. A valid evaluation method can identify no useful history effect; failure to find an adaptive gain does not disprove DTR/OPE. Conversely, a mathematically identified value can remain too imprecise or expensive to be useful.

### Theory versus innovation

The reviewed fixed-policy EIF/drift, opportunity factorization, selected-branch score/variance/allocation, kernel-coupling and prospective replicated-block arguments have no new blocking algebra defect found in this limited independent reconstruction under their stated assumptions. This is not an exhaustive line-by-line proof certification. Known randomization, support, fixed execution kernels, valid observation/retention, independent evaluation units and appropriate nuisance limits remain substantive assumptions; numerical tests do not establish them in deployment.

The principal statistical tools are inherited. [Jiang and Li (2016)](https://proceedings.mlr.press/v48/jiang16.html) already give sequential DR evaluation and safe-improvement applications. [Li et al. (2023)](https://proceedings.neurips.cc/paper_files/paper/2023/hash/98d0ad88db1e51bd0aa341a823290ece-Abstract-Conference.html) precede the narrower branch allocation with sequential evaluation design; [Lobel and Parr (2024)](https://rlj.cs.umass.edu/2024/papers/Paper106.html) precede the kernel bound's coupling principle. [BAAR](https://arxiv.org/abs/2602.21227) already studies stepwise agentic model routing; [Causal LLM Routing](https://arxiv.org/abs/2505.16037) supplies a causal query-routing precedent; [Replay Gap](https://arxiv.org/abs/2608.08239) already motivates the wrong-downstream-world problem. This bounded primary-source comparison is not an exhaustive novelty search.

The strongest defensible contribution is therefore a **validated full-policy evaluation contract** joining interventions, support, selective continuation measurement, execution/retention laws, uncertainty and fresh execution. The three extensions clarify how that contract works; they are not new general estimators, a global optimal exploration theorem or evidence of economical agent evaluation. Their practical added value has not yet been demonstrated. The current [claim map](paper_positioning.md) and [manuscript abstract](../manuscript/main.tex) already acknowledge much of this. More notation/proofs or manuscript length will not solve the empirical contribution gap.

A consequential design fact is that matched-initial H/P improvement requires reaching histories where the policies disagree. Low contrast variance caused by identical routers is not a successful discrimination study. The [shared-initial logger note](theory_primary_logger_candidate_20260926.md) makes disagreement occupancy enter both the effect bound and variance bound; the positive synthetic variance mechanism does not establish useful real disagreement.

## 3. Evidence against the hoped-for practical claim

**The deployed learned router is fixed scheduling.** Every retained live path is large (542), large-small (16), or large-small-large (102). There is no reachable within-stage feedback tailoring in those660 paths. The initial feature set only distinguished benchmark identity, so the learner could not use rich task difficulty information to select the first model. Always-small was an interpretable baseline but insufficient to establish adaptation. The strong fixed comparator removes the apparent improvement claim.

**The test of sequential adaptation was weak.** Of542 first-call stops,104 fail hidden scoring; only118/660 episodes reach first repair.60/330 evaluation tasks lack surviving visible checks. These are feedback/stopping limitations, not evidence that continuing would necessarily repair failures. Hidden tests cannot be fed back to fix the archived router. The pilot checked feasibility/nondegenerate success but should have checked feedback validity and consequential opportunities before the main freeze. The lead owns this omission.

**The matched restricted learner produces no selected history contrast.** TRAIN-only depth-selection under the frozen one-SE rule chooses depth0 for both router classes, and final refits give the same S-L-L schedule. Zero disagreement is an informative negative result for this representation/class/harness. The FIT-selected depth2 history validation value0.6522 versus constant-rule0.6270 is directionally favorable but only a development hypothesis: difference0.0252 versus the history value's SE0.0543, not a validated paired effect. The0.6270 belongs to the FIT-selected S-S-L rule; it must not be misattributed to the final all-TRAIN S-L-L refit. A richer learner is possible, but unsupported by these data as an automatic remedy.

**Real-agent OPE superiority has not appeared.** Class-tailored DR0.614871 differs from fresh0.651515 by−3.6644pp. Inspected action/probability/arithmetic reconstruction found no mismatch; that leaves execution drift, variation, observation/retention and inference explanations open. Across five common representable deterministic targets, donor-compatible replay MAE0.016061 is slightly smaller than DR0.018235. This does not prove replay is better from one noisy reference cohort, but it contradicts a claim that this study demonstrated DR advantage over a competent replay comparator. Deliberately crude frozen-state stitching is a different comparator; beating it would not settle this question.

**Original-target uncertainty remains unresolved.** Reproducing a point or nominal task-paired band does not validate its fixed-benchmark execution law, family dependence or coverage. The original branch/log point−0.0146537 survives arithmetic reconstruction, but without-replacement prefix sampling, shared source, noisy paired continuations and665 reported lost/recovered completions require a design-aware joint observation/inference law. A selected42-task or realized-prefix conditional estimate changes the target. The [replicated-block theory](theory_replicated_block_inference.md) is prospective; one retained archive block cannot become many independent blocks.

Enormous range-only sufficient counts in the [precision note](theory_precision_design_20260926.md) are **not necessary sample-size lower bounds or proof of unaffordability**. Independent fixed task/family execution groups could be more efficient. Their actual independence/covariance, scientific margin and attainable precision still need to be justified and measured. Seeds and task IDs alone do not establish independence.

## 4. Was evaluation correct? A calibrated answer

The retained numerical calculations and specific parser safeguards have been independently reconstructed. Original hidden-verifier outcomes have not all been independently rerun. It is therefore inappropriate to certify all evaluations, the physical execution law or a complete study-wide correctness guarantee.

The later strict grader verifies declared identities, raw output, invocation/patch/parser/bundle bindings and production receipts. MISSING/ERROR remain unknown for algorithmic correctness; SKIPPED/XFAIL are not strict passes. Operational failure and unknown algorithmic correctness stay distinct. Pinned upstream scoring/parser semantics are preserved separately: executing their code is not verified official Docker execution or an interchangeable endpoint. This separation is a valid improvement.

The actual AK result is a concrete safeguard test. **27960658 FAILED2:0**,42m27s,8 images acquired,16 controls attempted,0 model calls. All wrappers ultimately return0, but both Matplotlib arms lack815 declared statuses after a localhost-resolution pytest plugin INTERNALERROR. The strict assessor rejects both. Sphinx's reference and unchanged controls satisfy the declared endpoint while its setup.py/tox.ini-only source delta violates the frozen equal-tree requirement. Stock installation errors remain in all task logs.14 accepted arms are not14 clean installations or7 fully qualified tasks. [Complete terminal review](req030ak_terminal_decision_20260930.md).

This is not currently a resource-access problem: the job obtained the full allocation/images, executed all controls, and observed RAM/storage below its caps. The lead released incompatible full-path requirements and delayed their systematic integration. Serial small probes and source tests addressed real hazards but were poorly organized as a scientific work program. Passing812 default/343 focused inert tests did not demonstrate real deployment or competence; the counts overlap and are not independent evidence.

### Which gates are intrinsic, and which did we choose badly?

Safety isolation, public-only model inputs, common pinned treatment/measurement, correct terminal scoring, retained denominators and justified support/inference are genuine scientific requirements. Literal whole-tree equality and repeating exact online-style stock installation at scoring under a read-only offline root are **study-specific design choices**, not universal causal requirements. AK must fail its declared contract; its failure is not scientific impossibility. Sphinx's public setup-only delta weighs against task-fix contamination. It cannot be silently waived after observation, but can be transparently accounted for in a newly frozen treatment.

A coherent future custom treatment could preserve declared task implementation/test paths, list/pin setup-only changes, install all dependencies once before collection with fatal build receipts, define loopback hostname resolution while retaining no external network, and keep runtime packages read-only with fresh bounded edit/evaluation workspaces. If installation is omitted at scoring because already completed, disclose that variant and do not claim official Docker equivalence. All assigned controls must be reviewed together; no passing subset. Existing images/source archives are reusable cache/provenance substrates, and qualified guardian/native/parser components can be reused. They are not already accepted environments. Transparent requalification after zero model exposure need not constitute model-outcome tuning, but requires a new complete prospective decision, not reopening AK automatically.

The prospective eight-task ×four fixed-schedule screen is also only a competence/opportunity screen:32 slots are not32 independent tasks, fixed p=1 schedules are not a randomized logger, and its spending floors are not significance/power guarantees. A succeeding screen would still leave training, matched H/P policies, known-probability logging/fresh runs and valid uncertainty to complete.

## 5. What the compute investment bought, and what it did not

It bought reusable execution/evaluation code, source/raw provenance, scoped synthetic validation, substantial descriptive real policy differences, and adverse evidence revealing feedback, comparator, retention and environment failures. These assets can support a narrower methodology/critical-case paper and reduce the cost of a carefully specified future study.

The13,164 count refers to retained newly completed calls in **one main archived coding study**:6063log+5504live+1434branch+163pilot. It is not total project compute. Durable branch decisions contain five additional earlier rows across four re-executed IDs. Unknown calls behind lost original completions, later model/browser/arithmetic pilots, image construction, load time and physical allocation are not covered. No complete monetary/energy or total compute-return ledger has been reconstructed. Requested time is not consumed GPU time; call counts are not prices.

It has not bought a competent new executor pair, validated practical adaptive-history benefit, real DR-over-replay accuracy/equal-budget gains, a valid original-target joint interval, or a confirmatory completed package. Adverse outcomes are scientific evidence, but repeated setup-only repairs are not repeated tests of the routing hypothesis.

## 6. Investment decision

**Do not expand or continue open-ended model/qualification spend on the strength of current evidence. Continue a bounded effort to finish the narrower evaluation-methodology/critical-case paper.** That is the present recommendation, not a claim that the scientific question is false or a command to cancel the existing monitor/goal state.

One further coherent development decision could be rational if the author values the broader empirical question, but it must have a fixed total engineering/qualification/model resource envelope and a predetermined fallback to the narrower paper. Its pre-outcome contract must resolve all of these together:

1. Fully executable common source/environment and independent correct/broken/missing-output scoring; all assigned unchanged/reference controls; no selected passing subset.
2. A prospectively fixed comparable executor pair and operational competence screen; enough deployable feedback and active policy disagreement to test consequential second decisions.
3. A strong fixed comparator and matched-initial H/P learner/feature/budget contract; known logging probabilities and separate fresh whole-policy execution, with unexposed/family-safe analysis partitions.
4. The fixed target, correct execution-independent unit, uncertainty/algorithmic-unknown rules and achievable numerical scientific precision, including total training/acquisition cost.

Do not count a submitted job, enlarged model or positive control as meeting these conditions. Do not search successive cohorts until something passes or alter margins/utilities after outcomes. If an integrated bounded contract cannot be made executable, or the prospectively measured screen rejects competence/opportunity, stop empirical expansion and finish the narrower paper. If a valid well-powered H/P comparison is null, that is an acceptable scientific endpoint rather than a reason to keep spending. A mere nonsignificant result at poor precision remains inconclusive.

Evidence against abandoning the question entirely includes sizable executor differences, reproducible synthetic error gains, supported history-feature variation and a weak directional development history signal; the new HF/BF16 pair remains unmeasured. Evidence against optimistic expansion is stronger for current readiness: fixed learned scheduling, matched-rule collapse, poor feedback eligibility, unresolved real calibration/inference and recurring incompatible qualification contracts. The recommended boundary is a finite discriminating investment, not either a promise of positive results or indefinite repair.
